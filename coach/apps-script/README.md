# 紀律健身房：雲端存檔與 AI 教練設定教學

做完以後：
- 每次在遊戲交表，紀錄會自動存進**你自己的 Google 試算表**（永久保存，換手機也能下載回來）
- 遊戲的「💬 問教練」會用 **Gemini AI** 回答，並由教練說出來
- Gemini API key 只存在你的 Apps Script 裡，不會出現在網頁或 GitHub 上

全部免費，大約 10 分鐘。建議用電腦操作，手機也可以。

---

## 步驟 1：申請 Gemini API key
1. 打開 https://aistudio.google.com/apikey ，用 Google 帳號登入
2. 按 **Create API key**（建立 API 金鑰）
3. 複製這串 key（`AIza` 開頭），等一下會用到
4. ⚠️ 這串 key 不要貼到聊天、GitHub 或任何網頁上

## 步驟 2：建立試算表和 Apps Script
1. 打開 https://sheets.new ，建立一個新的 Google 試算表，命名為「紀律健身房紀錄」
2. 上方選單 **擴充功能 → Apps Script**
3. 把編輯器裡原本的程式全部刪掉，貼上同資料夾 [`Code.gs`](Code.gs) 的全部內容
4. 按 💾 儲存，專案名稱可以取「紀律健身房後端」

## 步驟 3：設定 key 和暗號
1. Apps Script 左側點 ⚙️ **專案設定**
2. 拉到最下面 **指令碼屬性** → **新增指令碼屬性**，新增兩筆：

| 屬性 | 值 |
|---|---|
| `GEMINI_API_KEY` | 步驟 1 複製的 key |
| `APP_TOKEN` | 自己編一組暗號，例如 `yaha-2026-run`（不要用常見密碼） |

3. 按 **儲存指令碼屬性**
4. （選填）想換模型，可以再新增 `GEMINI_MODEL`，例如 `gemini-2.5-flash`（預設值）

## 步驟 4：測試 Gemini（選做）
1. 回到左側 **編輯器** `< >`
2. 上方函式選單選 `testGemini`，按 ▶ **執行**
3. 第一次會要求授權：按 **審查權限** → 選你的帳號 → **進階** → **前往（不安全）** → **允許**
   （這是你自己寫的程式，Google 對未審核的個人程式都會這樣提醒）
4. 下方「執行記錄」出現一句加油的話，就代表 key 可以用

## 步驟 5：部署成網頁應用程式
1. 右上角 **部署 → 新增部署作業**
2. 齒輪 ⚙️ 選 **網頁應用程式**
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（遊戲要能從手機連進來；沒有暗號的人什麼都讀不到）
4. 按 **部署**，第一次會再要求授權，同上按允許
5. 複製 **網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`）

## 步驟 6：在遊戲裡連線
1. 打開遊戲 → **⚙️ 設定** → **☁️ 雲端存檔與 AI 教練**
2. 貼上步驟 5 的網址，暗號填步驟 3 的 `APP_TOKEN`
3. 按 **💾 儲存並測試連線**，看到「✅ 連線成功，Gemini 已設定」就完成了
4. 第一次建議按 **⬆️ 上傳全部紀錄**，把手機裡的舊紀錄存上去

## 之後怎麼用
- **自動存檔**：每次在登記櫃台按「交給教練」，就會同步到試算表的 `records` 分頁
- **換手機／清掉資料**：在新手機填好網址和暗號，按 **⬇️ 從雲端下載**
- **問教練**：健身房畫面按 **💬 問教練**，可以點快速問題，例如「點評今天」「晚餐建議」，或自己打字問。教練會參考你近 7 天的紀錄回答
- **圖表**：「📈 紀錄」頁的體重趨勢和每週運動圖表，會用同步下來的全部紀錄來畫

## 修改了 Code.gs 之後
要讓修改生效：**部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**。這樣網址不變，遊戲不用重設。

## 常見問題
- **顯示「暗號 APP_TOKEN 不正確」**：遊戲填的暗號和指令碼屬性的不一樣（注意大小寫和空白）
- **顯示 Gemini 錯誤 400／403**：API key 貼錯或失效，到 AI Studio 重新建立一組
- **顯示 Gemini 錯誤 429**：免費額度暫時用完，等一下再問
- **連線失敗**：確認部署時「誰可以存取」選的是 **所有人**，網址結尾是 `/exec`
